# 🚀 GenAI Inventory Decision-Support System

A full-stack AI application designed to bridge the gap between raw data and executive decision-making. 

### 🛠️ The Tech Stack (10-Layer Architecture)
* **Model:** Llama 3.1 8B (via Groq LPU for <1s latency)
* **Logic:** RAG (Retrieval-Augmented Generation) 
* **Framework:** Flask (Python backend)
* **UI:** Custom HTML/CSS Dashboard

### 📊 Key Features
* **Live Stock Insights:** Real-time data processing from Kaggle datasets.
* **Grounded Reasoning:** Uses RAG to ensure shipping and safety policies are followed.
* **Automated Procurement:** Generates draft reorders and supplier emails instantly.

### 📈 Business Impact (KPIs)
* **Reporting Efficiency:** 30 minutes → 3 minutes.
* **Accuracy:** 100% grounded in provided inventory data.
